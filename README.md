# Переводы Existential Comics

Здесь мы переводим комиксы о философии с
[existentialcomics.com](https://existentialcomics.com). Переводы
неофициальные и некоммерческие, делаются и распространяются с
полученного 2026-07-31 от автора (Corey Mohler) согласия.

Пока налаживаем процесс разработки. Предстоит подобрать или нарисовать
шрифт, подробнее задокументировать и проработать процесс. Основные его
ступени:

1. Берём комикс, избегая небезопасных для публикации в РФ тем.
2. Составляем текстовую транскрипцию на английском языке.
3. Переводим транскрипцию на русский язык.
4. Редактируем тексты реплик на изображениях.

Таким образом, стараемся не терять метаданные (включая ссылки на
оригиналы и на их автора, текстовый комментарий под комиксом), и
получаем дополнительный (текстовый) вариант для хранения и
распространения комиксов, к тому же удобный для поиска по ним. Также
переводом и редактированием изображений могут заниматься разные
участники, и они могут исправляться или дополняться со временем.

Сохраняем получившиеся комиксы в PNG формате, избегая сжатия с
потерями. Для рабочих версий изображений с редактируемыми текстами, по
возможности сохраняем их в XCF формате, с "замазкой" оригинальных
текстов отдельным слоем (т.е. сохраняя оригинал целиком, нижним
слоем). Используем шрифт [TroubleSide
Comic](https://www.fontspace.com/troubleside-font-f58132).
